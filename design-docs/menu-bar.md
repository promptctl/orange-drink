# Menu Bar

Chooses what the menu bar icon looks like, shows a preview of it, and points the user to how to hide the system battery icon.

**Header:** mint-green tile with a white window outline, title "Menu Bar".
**Subtitle:** "Customize how {App} appears in your menu bar"

## Menu Bar Icon

Section icon: cyan rounded window outline with a top bar.

One large card. It opens with a three-option radio list. Each option row has a bold white title, a grey description, and a selection marker on the far right: a filled green circle with a white checkmark when selected, an empty grey ring otherwise.

| Option | Description | Selected |
| --- | --- | --- |
| Battery Indicator | "Shows battery level and charging status – {App}'s opinionated design" | yes |
| Minimal | "Minimalistic iPhone-style battery indicator" | no |
| {App} Logo | "Static {App} logo icon" | no |

Below the radio list, still inside the card, four settings rows with icon tiles. They're indented slightly more than the radio rows:

1. **Display.** Purple tile with a checklist glyph. Description "Choose what to display in the menu bar icon". Pop-up button, value "Percentage". Presumably the other values include time remaining and icon only.
2. **Color.** Orange tile with a half-filled circle. Description "Match your menu bar style". Pop-up button, value "Light".
3. **Size.** Blue tile with the glyph "AA" (small A, large A). Description "Make the icon and its text larger and easier to read". Pop-up button, value "Default".
4. **Status colors.** Green tile with a paint-palette glyph. Description "Green when charging, orange for low battery. Off keeps the icon neutral and only turns red when critical." Switch, on, in indigo.

### Preview

A grey "Preview" label, then a centred mockup about 270 × 190 pt with rounded corners:

- **Menu bar:** a thin bar across the top of the mockup, with the Apple logo on the left and the app's battery icon on the right. The icon is a small rounded battery outline, partly filled, with "75" printed inside it.
- **Background:** a dark green gradient, like a desktop wallpaper.
- **Arrow:** a hand-drawn white arrow curves up from the lower middle to point at the battery icon.
- **Two numbered tips** in the lower left, each a circled number followed by white text, with a grey sub-line underneath that ends in a circled "?" help button:
  1. "Control {App} from the menu bar" / "Don't see it?"
  2. "Remove default battery icon from menu bar" / "Click to see quick tutorial"

The "Don't see it?" help covers menu bar overflow, where the icon is hidden behind the notch or by too many other icons. The tutorial shows how to turn off the system battery icon in Control Center settings.

The preview updates live as the options above change.
